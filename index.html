Clean REST Architecture Meets Supervised AI

Answering the core capstone question by demonstrating how generative AI can accelerate scaffolding while deterministic compilers and automated testing eliminate contract drift and hallucinations.

⚡ Static GitHub Pages vs. Live FastAPI Backend
Key Concept for Evaluators: GitHub Pages provides static HTML, CSS, and JavaScript hosting. It cannot execute Python, run Uvicorn, or bind to an SQLite database file. This GitHub Pages deployment serves as the public interactive documentation portal and contract viewer. To execute real database transactions, live borrowing workflows, and interactive Swagger UI calls, execute run.bat locally.
🛡️

Strict RFC 9110 HTTP Semantics

Resource-oriented URIs using plural nouns. Correct distinction between PUT (complete replacement) and PATCH (partial updates). Zero action verbs in URL paths.

📑

Zero Documentation Drift

FastAPI generates OpenAPI 3.1.0 specifications directly from Python type hints and Pydantic v2 schemas at runtime. The documentation and the code are inherently synchronized.

🔒

Invariant & Concurrency Guards

Atomic transactions prevent available book copies from dropping below zero. Deleting books with active loans is rejected with 409 Conflict.

🧪

Automated Pytest Suite

22 automated unit and integration tests executing against isolated temporary database sessions. Verifies success paths, edge cases, negative boundaries, and error envelopes.

🤖

Responsible AI Governance

100% of AI-generated code is audited through compiler and test checks. Zero fabricated citations or hallucinated test counts. Synthetic student personas ensure privacy by design.

🔍

CI/CD Documentation Linter

Includes scripts/check_documentation.py, an automated tool that inspects the OpenAPI spec and fails with exit code 1 if routes are missing.

API Contract

Library Management Endpoint Inventory

All endpoints are mounted under the versioned base path /api/v1 and adhere to standardized HTTP status codes and error envelopes.

Method Endpoint URI Operation Purpose Parameters / Body Status Codes
GET /health Service health check and database connectivity probe None 200 OK
GET / Root navigation index with documentation links None 200 OK
GET /api/v1/books List library books with pagination and substring search Query: limit, offset, search 200 OK 422
GET /api/v1/books/{book_id} Retrieve a single book resource by primary key ID Path: book_id (int >= 1) 200 OK 404
POST /api/v1/books Create a new book in inventory (validates unique ISBN) Body: BookCreate JSON 201 Created 409 422
PUT /api/v1/books/{book_id} Complete replacement of existing book metadata Path: book_id, Body: BookUpdate 200 OK 400 404
PATCH /api/v1/books/{book_id} Partially update one or more book attributes Path: book_id, Body: BookPatch 200 OK 404
DELETE /api/v1/books/{book_id} Delete book (rejected with 409 if active loans exist) Path: book_id 204 No Content 409
POST /api/v1/books/{book_id}/borrow Borrow an available copy; decrements available inventory Path: book_id, Body: BorrowRequest 201 Created 409
POST /api/v1/books/{book_id}/return Return a borrowed copy; restores available inventory Path: book_id, Body: ReturnRequest 200 OK 404
GET /api/v1/borrowings List historical borrowing records with status filters Query: limit, offset, status, book_id 200 OK 422
Technology Choices

Built with Free & Open-Source Tools

Engineered exclusively with permissive open-source libraries. Zero paid APIs, cloud subscriptions, or external AI API keys required.

FastAPI v0.162

Modern, high-performance web framework providing native OpenAPI 3.1.0 reflection, dependency injection, and ASGI concurrency.

Pydantic v2.14

Strict runtime data validation, regex formatting for ISBNs, range limits, and standardized error response serialization.

SQLAlchemy v2.1

Enterprise-grade Python ORM providing relational modeling, transaction management, and pure Python fallbacks.

SQLite 3 Embedded

Zero-configuration, serverless, persistent relational database storing all library inventory in a single local disk file.

Pytest v8.4

Automated test runner executing 22 unit, integration, and edge-case test cases in 1.06 seconds with complete isolation.

Uvicorn v0.54

Lightning-fast ASGI production web server serving HTTP requests with automatic code reloading during development.

Execution Guide

How to Run the Application Locally

To execute live database queries, borrow books, and explore interactive Swagger UI, clone the repository and run the server locally. 

:: 1. Navigate to the project root in CMD or PowerShell
cd path\to\rest-api

:: 2. Execute the one-click automated startup script
run.bat

:: run.bat automatically:
:: - Checks Python 3.11 installation
:: - Creates the .venv virtual environment
:: - Installs requirements.txt
:: - Seeds 5 demo textbooks safely into library.db
:: - Starts Uvicorn on http://127.0.0.1:8000

:: 3. Open your browser to explore interactive Swagger UI:
http://127.0.0.1:8000/docs
# 1. Grant execute permissions to the startup script
chmod +x run.sh

# 2. Run the startup script
./run.sh

# 3. Open your web browser to:
http://127.0.0.1:8000/docs
# Execute the 22 automated integration tests:
python -m pytest -v

# Run the OpenAPI route consistency checker:
python scripts/check_documentation.py

# Run end-to-end live endpoint verifier:
python scripts/verify_endpoints.py
